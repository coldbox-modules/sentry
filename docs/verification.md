## CI failure repair: 2026-10-04

The failing head `39865b9` had three infrastructure problems: the workflow did not start the local envelope receiver, the root harness referenced the sentry mapping before creating it, and the tests application called a BoxLang-only environment BIF on CFML engines. The workflow now starts and checks the receiver, retains its log as an artifact, and probes a non-throwing health template with HTTP failure detection. Environment lookup uses Java System.getenv. Formatting uses CommandBox CFFormat 0.21.0 in both local and CI checks, with no automatic formatting commits.

The local engine runs also exposed module compatibility issues. Adobe rejects local declarations that reuse argument names and direct indexing of a struct literal. Lucee rejects slicing an empty pending array and returns false for every() on an empty array. Transport now handles an empty flush explicitly. Adobe on Java 21 cannot reflect on non-exported JDK HTTP implementation classes; JavaHttp invokes methods declared on exported HTTP/Future interfaces instead. This requires no extra JVM access flags or consumer JAR. The public-interface approach follows the [Java Method invocation contract](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/reflect/Method.html#invoke(java.lang.Object,java.lang.Object...)).

Queue cleanup iterates a Java key array rather than relying on engine-specific entrySet iteration. Metadata lookup guards missing keys explicitly. Observer catches increment a thread-safe diagnostic count exposed by getObservationFailureCount(), without exporting exception contents or invoking telemetry recursively. Regression specs assert zero observer failures during timeout/retry and chained publication. The cross-thread fixture holds the original observer in a Java AtomicReference because Adobe copies CFML thread arguments. The query-listener fixture uses an actual caught exception rather than an artificial exception struct.

With ColdBox 7.5.2+27 and TestBox 3.2.0, the default harness passes 45/45 on BoxLang 1.18.0+66, Lucee 6.2.8.20, and Adobe CF 2023 update 25 (2023,0,25,330977), using Java 21.0.10+7.
